# Синхронизация

## Синхронизация языков

Модуль поддерживает мультиязычность, поэтому для каждого языка создаются отдельные деревья. В модуле поддерживаются по умолчанию два языка Русский и Английский. Для удобства к названиям деревьев добавляется языковая приставка (например, `.ru` или `.en`). Чтобы обеспечить целостность данных, используется механизм синхронизации между деревьями.

:::info
При добавлении нового атрибута в дерево `.ru`, в дерево `.en` автоматически добавится атрибут с названием "New attribute".

При добавлении нового атрибута в дерево `.en`, в дерево `.ru` автоматически добавится атрибут с названием "Новый атрибут".
:::

Аналогично для **Групп Атрибутов**.

## Синхронизация узлов дерева

Синхронизация применяется к следующим элементам:

- Шаблоны
- Значения

При изменении одного из этих узлов другой перезагружается автоматически с учетом изменений.

Дежурные шаблоны **не синхронизируются**.

## Синхронизация деревьев

Изменения синхронизируются во всех деревьях, где присутствует изменяемый узел.
При этом перезагружаются только затронутые узлы, а не все дерево.

Синхронизация языков также распрстраняется на все деревья.

:::warning
Если синхронизация не работает, проверьте настройки мультиязычности и целостность базы данных.
:::
