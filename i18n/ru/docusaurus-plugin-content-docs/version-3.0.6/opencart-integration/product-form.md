# Интеграция с формой товара

Интеграция модуля с движком OpenCart осуществляется с помощью файлов модификаторов `ocmod`. О назначении файлов в разделе [Структура архива](/technical-specifications/archive-content.md). Об установке модификаторов в разделе [Установка](/install-update/install.md).

Если модификация прошла корректно, то в сайдбаре административной панели в меню *Каталог ⇒ Характеристики* должен появиться пункт **Attribut&pro**, а в форме товара должна появиться одноименная вкладка.

Перейдя на эту вкладку вы увидите таблицу **Атрибутов** товара с их **Значениями**. 

В таблице поддерживается сортировка по одному из столбцов и постраничный вывод **Атрибутов**. Слева есть чекбоксы для выбора строк таблицы подлежащих удалению.

В верхней части таблицы присутствует специальная панель с элементами управления.

:::tip
Все манипуляции с данными в таблице сразу записываются в Базу Данных.
Если вы не вносили изменений на других вкладках, нажимать кнопку сохранения необязательно.
:::
