# Атрибуты категорий

Интеграция со страницей товара позволяет автоматизировать процесс добавления **Атрибутов категории** в товар.

Добавление **Атрибутов категории** происходит в момент "привязки" товара к определенной категории.
Физически это происходит в момент двойного клика на категорию в дереве категорий при условии, что отмечен чекбокс `Добавлять атрибуты автоматически`.

Удаление **Атрибутов категории** происходит в момент "отвязки" товара от категории. Удаление **Атрибутов** необходимо подтвердить во всплывающем окне. Если отмечен чекбокс `Удалять атрибуты автоматически`,
то удаление произойдет без подтверждения.

Чтобы добавить все **Атрибуты** всех категорий, к которым "привязан" товар, воспльзуйтесь кнопкой `Атрибуты категорий`.
![Green button](/img/tutorial/green_button.png)

Добавление **Значений атрибутов категории** или точнее их **Дежурных шаблонов** в товар происходит в соответствии со [**`Способом вставки значений`**](/opencart-integration/method-inserting.md).

:::info
Все, что описано выше по поводу добавления **Атрибутов категорий** и их **Значений**, касается одного, конкретного, редактируемого товара.

Если необходимо добавить **Атрибуты категории** во все товары какой-либо категории, используйте Drag'n'Drop и другие возможности [модуля](/module-features/category-attributes.md) или воспользуйтесь инструментом [Атрибуты категорий](/tools/category-attributes.md).
:::
