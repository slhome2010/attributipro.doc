# Новое в этой версии

1. Добавлен инструмент 'Перераспределение атрибутов'.
   Инструмент позволяет эффективно перераспределять атрибуты между группами. Имеет несколько режимов, включая искусственный интеллект.
   Полезен после импорта и парсинга.
2. Улучшен инструмент 'Объединение дублей'.
   Инструмент позволяет эффективно объединять дубликаты атрибутов. Имеет несколько режимов, включая искусственный интеллект.
   Полезен после импорта и парсинга.
3. Усовершенствован алгоритм импорта в формате CSV. Повышена производительность.
4. Добавлена возможность управления статусами атрибутов и их значений и их видимости в фильтре и карточке товара.
5. Во всех формах редактирования метаданных Атрибутов, Дежурных шаблонов, Значений (в товаре) появилась кнопка автозаполнения с применением искусственного интелекта.
