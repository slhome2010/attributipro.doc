# Единицы измерения

Этот инструмент позволяет прикрепить единицы измерения непосредственно к названию **Атрибутов**, **Значений** или **Дежурных Шаблонов**.

Стиль отображения единиц измерения выбирается из выпадающего списка.

| ![Tools Unit](/img/tutorial/tools_unit.png) |
|:--:|
| *Tools for Unit unification* |

## Атрибуты до применения инструмента

| ![Tools Unit](/img/tutorial/tools_unit_before_value.png) |
|:--:|
| *Display before attaching units* |

## Пример для значений и дежурных шаблонов

| ![Tools Unit](/img/tutorial/tools_unit_after_value.png) |
|:--:|
| *Display after attaching units* |

Единицы измерения прикрепляются к каждому **Значению** даже если они записаны через разделитель.

Обратите внимание, что **Значение** `1500` осталось без изменений.

:::info
Единицы измерения должны быть сохранены в метаданных, иначе нечего будет прикреплять.
:::

## Пример для атрибутов

Можно не *перегружать* вид информацией, а прикрепить единицы измерения только к атрибуту.

| ![Tools Unit](/img/tutorial/tools_unit_after_attribute.png) |
|:--:|
| *Display in Attribute name* |

:::info
Не стоит использовать этот инструмент если вы собираетесь включить видимость единиц измерения только на фронтенде.
:::
