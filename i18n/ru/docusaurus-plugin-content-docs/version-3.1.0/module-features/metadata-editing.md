# Метаданные атрибута

Форма редактирования метаданных запускается повторным нажатием `Shift + Click` в режиме однострочного редактора или при нажатии `F2` на выбранном **узле**, или через [контекстное меню](/module-features/context-menu.md).

Форма загружается в модальном окне. Например, форма метаданных **Атрибута** выглядит так:

## Заполнение Дежурного Шаблона

Если необходимо ввести или изменить только значение **Дежурного шаблона**, то сделайте это в соответствующем поле ввода.

Если нажать на кнопку поиска справа от этого поля, то включится подгрузка уже имеющихся в товарах **Значений**. Если таких **Значений** нет, список не сформируется.
Список фильтруется по принципу автозаполнения. Например, при вводе числа _3_ система может предложить варианты: _3,0_, _3,2_, _3200_.

Для **Дежурного шаблона** можно создать свои метаданные, но для этого придется их заполнить в [другой форме](/module-features/duty-features.md).

## Заполнение формы с помощью ИИ (Волшебная кнопка)

Вы можете автоматически заполнить поля формы метаданных атрибута с помощью Искусственного Интеллекта. Для этого нажмите кнопку с иконкой магии (✨) в верхней части формы (рядом с полем Дежурного шаблона).

ИИ проанализирует название группы атрибута и текущего атрибута, после чего автоматически сгенерирует:

- Ясное и точное **Описание** (используется как Tooltip)
- Подберет подходящую **Иконку** из набора Font Awesome
- Выберет наиболее подходящую **Единицу измерения** из доступных в системе

:::note
ИИ не заполняет поле Дежурного шаблона. Для работы генерации требуется настройка OpenAI API ключа.
:::

## CKEditor

В качестве редактора описаний используется CKEditor. CKEditor – это редактор формата WYSIWYG. Подробнее о возможностях редактора можно узнать на [официальном сайте CKEditor](https://ckeditor.com/).

Описания в дальнейшем используются в качестве всплывающих подсказок.

## Локализуемые и нелокализуемые метаданные

Все описанные в предыдущих разделах [метаданные](/general-info/metadata.md) относятся к локализуемым, или зависящим от выбора языка. Метаданные, находящиеся ниже разделительной линии с надписью `Общая часть`, относятся к нелокализуемым и применяются для всех языков (например, английского, русского, испанского) одинаково.

Если вы хотите сделать полное клонирование, то, перед сохранением формы, отметьте чекбокс `Применить для всех языков`.

## Изображение и иконка

Чтобы загрузить изображение, нажмите Изображение ➔ выберите файл через файловый менеджер OpenCart.

Иконка прописывается так же, как в HTML-вёрстке, только без оборачивающих тегов. В данном примере используется [библиотека **Font Awesome**](https://fontawesome.com/). Пример: `fa fa-tablet` соответствует иконке планшета.
