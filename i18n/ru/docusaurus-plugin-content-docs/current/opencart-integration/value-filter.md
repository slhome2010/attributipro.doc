# Фильтр значений

В магазинах с большим количеством товаров и **Атрибутов** список **Значений** может быть очень длинным. Это вызывает определенные неудобства при заполнении формы. Фильтр позволяет ограничить список.

| ![attribute](/img/tutorial/value_filter.png) |
|:--:|
| *List Filter* |

| **Переключатель** | **Список** |
|:--|:--|
| `Все` | отображение всех **Значений** данного **Атрибута** для всех товаров, плюс **Дежурный шаблон** |
| `Категории` | отображение **Значений** только товаров из категорий отмеченных на вкладке **Связи** (не путать со **Значениями атрибутов категорий**) |
| `Дежурные` | выдача **Значений** [Дежурного шаблона](general-info/duty.md) |

Фильтр работает в оперативном режиме, перезагрузка списка **Значений** происходит сразу после переключения режима. Настройка сохраняется на время сессии.
