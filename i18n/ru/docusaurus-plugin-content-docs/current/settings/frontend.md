# Фронтенд

Данная документация описывает интерфейс настройки отображения [метаданных](general-info/metadata.md) атрибутов и их значений на фронтенде.

| ![Frontend Settings](/img/tutorial/frontend_settings.png) |
| - |
| *Frontend metadata settings* |

## Основные элементы интерфейса

**Вкладки:**

- Товар: Видимость метаданных на странице товара.
- Фильтр: Видимость метаданных в фильтре.
- Резерв: Резервная вкладка.

**Таблица настроек:**

Состоит из двух столбцов:

- **Атрибут**: Настройки видимости метаданных атрибута товара.
- **Значение**: Настройки видимости метаданных значения атрибута.

**Каждая строка таблицы представляет собой настройку включения видимости для конкретного элемента метаданных:**

- Изображение: Настройка отображения изображения атрибута или значения.
- Иконка: Настройка отображения иконки.
- Иконка подсказки: Настройка отображения иконки наличия подсказки.
- Описание: Настройка отображения текста для всплывающей подсказки.
- URL: Настройка отображения значка наличия ссылки перелинковки.
- Автогенерация URL: Настройка разрешения [автоматической генерации](/settings/interlink.md) ссылки перелинковки.
- Единицы: Настройка отображения единиц измерения.
- Стиль отображения: Настройка стиля отображения единиц измерения.

**Выпадающий список "Стиль отображения": Позволяет выбрать стиль отображения единиц измерения:**

- Clockspeed (MHz)
- Clockspeed, MHZ
- Clockspeed (Megahertz)
- Clockspeed, Megahertz
- Clockspeed (Megahertz, MHz)
- Clockspeed, Megahertz, MHz

## Модификация фронтенда

Большинство магазинов для фронтенда используют дизайнерские темы и шаблоны, а также сторонние приложения фильтров.
Поэтому не существует универсальных способов для изменения чужого дизайна или приложения.

Используемый в этом модуле подход является только примером, который, возможно, кому-нибудь пригодится.

:::info
Все модификаторы предназначены для нативного дизайна и программного обеспечения OpenCart.
:::

Файлы модификаторов находятся в [папке](/technical-specifications/archive-content.md) `ocmod/`.

`attributipro3.frontend.product.ocmod.zip` файл модификатор карточки товара на фронтенде для магазинов версии 3.x.
`attributipro3.frontend.filter.ocmod.zip` файл модификатор фильтра на фронтенде для магазинов версии 3.x.

Файлы взаимодействия с бэкендом находятся в [папке](/technical-specifications/archive-content.md) `catalog\`.

Все файлы для фронтенда поставляются с открытым исходным кодом.
