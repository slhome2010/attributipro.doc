# Настройки AI

| ![Attributico AI settings](/img/tutorial/v307/settings_ai_ru.png) |
| :---------------------------------------------------------------: |
|                     _Attributico AI settings_                     |

Вкладка настроек AI позволяет настроить интеграцию искусственного интеллекта для обработки атрибутов и данных.

| Пункт               | Описание                                                  |
| ------------------- | --------------------------------------------------------- |
| **Ключ API OpenAI** | Ваш ключ API OpenAI. Необходим для доступа к функциям AI. |
| **Модель**          | Выберите модель AI, которую вы хотите использовать.       |

## Рекомендации по API-ключу

Для получения API-ключа зарегистрируйтесь на платформе OpenAI и создайте стандартный ключ доступа к API в личном кабинете.
Вы можете смело использовать недорогие модели. Для задач, выполняемых модулем, базовых и доступных моделей вполне достаточно, что позволяет оптимизировать затраты без потери качества.
