# Дежурный Шаблон

## Создание дежурного шаблона

Создание [**Дежурного шаблона**](/general-info/duty.md) производится на вкладке _`Атрибуты`_ или на вкладке _`Атрибуты категорий`_, если в настройках дерева добавлен _узел_ **Дежурного шаблона**.

На выбранном _узле_ **Дежурного шаблона** нужно войти в режим [редактирования](/module-features/editing.md), после чего ввести необходимые значения по умолчанию через [разделитель](/general-info/values-templates.md) если их несколько.

Если нужен доступ к **Метаданным дежурного шаблона** то при повторном нажатии `Shift + Click` в режиме редактирования или при нажатии `F2` на выбранном **узле**, или через [контекстное меню](/module-features/context-menu.md) можно загрузить специальную форму.

## Метаданные дежурного шаблона

Каждый **Дежурный шаблон** может иметь дополнительные [**Метаданные**](general-info/metadata.md), которые становятся в полном смысле **Дежурными метаданными** или метаданными по умолчанию, которые подставляются в метаданные **Значения** атрибута одновременно с **Дежурным шаблоном**.

## Удаление дежурного шаблона {#using-duty-del}

Удаление (очистка) **Дежурного шаблона** производится через [контекстное меню](/module-features/context-menu.md) или клавишей `Del`.

Операцию можно производить только на вкладке _`Атрибуты`_. Данная операция не затрагивает товары. Удаляется только **Дежурный шаблон** со своими метаданными.

---

## Клонирование дежурного шаблона {#using-duty-clone}

Очень часто **Дежурный шаблон** представляет собой набор числовых значений, не нуждающихся в переводе на другие языки. Например, `20°C - 40°C`, или `2G/3G (WCDMA/UMTS)/4G (LTE)`.

Заполнив **Дежурный шаблон** для одного языка, можно сразу клонировать его в другие языки.

Клонирование **Дежурного шаблона** производится через [контекстное меню](/module-features/context-menu.md) или по сочетанию клавиш `Alt + C`.

Метаданные клонируются вместе с **Дежурным шаблоном**.

## Заполнение формы с помощью ИИ (Волшебная кнопка)

Вы можете автоматически заполнить поля формы метаданных с помощью Искусственного Интеллекта. Для этого нажмите кнопку с иконкой магии (✨) в верхней части формы дежурного шаблона.

ИИ проанализирует название группы атрибута и самого атрибута, после чего автоматически сгенерирует для **Дежурного шаблона**:

- Практичную **Всплывающую подсказку** (tooltip)
- Подберет подходящую иконку из набора **Font Awesome**
- Выберет наиболее подходящую **Единицу измерения** из доступных в системе

:::note
Для работы этой функции у вас должен быть настроен OpenAI API ключ в настройках модуля. ИИ учитывает выбранный язык редактирования и возвращает результат на соответствующем языке. Значение самого шаблона ИИ не генерирует, так как оно требует вашего специфического ввода.
:::
