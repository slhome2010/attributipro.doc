# Редактирование метаданных

Форма редактирования метаданных запускается повторным нажатием  `Shift + Click` в режиме однострочного редактора или по нажатию `F2` на выбранном **Узле**, или через [контекстное меню](/module-features/context-menu.md).

Форма загружается в модальном окне и выглядит так:

| ![Metadata editing form](/img/tutorial/form_attribute.png) |
|:--:|
| *Metadata editing form* |

## Редактирование дежурного шаблона

Если необходимо ввести или исправить только значение **Дежурного шаблона**, то сделайте это в соответствующем поле ввода.

Если нажать на кнопку поиска справа от этого поля, то включится подгрузка уже имеющихся в товарах **Значений**. Если таких **Значений** нет, то список не сформируется.
Список фильтруется по принципу автозаполнения.

Для **Дежурного шаблона** можно создать свои метаданные, но для этого придется их заполнить в [другой форме](/module-features/duty-features.md).

## CKEditor

В качестве редактора описаний используется CKEditor. CKEditor – это редактор формата WYSIWYG.
Описания в дальнейшем используются в качестве всплывающих подсказок.

## Локализуемые и нелокализуемые метаданные

Все описанные в предыдущих разделах [метаданные](/general-info/metadata.md) относятся к локализуемым, или зависящим от выбора языка. Метаданные, находящиеся ниже разделительной линии с надписью `Общая часть`, относятся к нелокализуемым и применяются для всех языков одинаково.

Если вы хотите сделать полное клонирование, то, перед сохранением формы, отметьте чекбокс `Применить для всех языков`.

## Изображение и иконка

Выбор изображения делается с помощью встроенного в OpenCart файлового менеджера.

Иконка прописывается так же, как в HTML-верстке, только без оборачивающих тегов. В данном примере используется библиотека **Font Awesome**.
