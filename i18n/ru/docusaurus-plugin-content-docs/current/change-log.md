# Новое в этой версии

1. Улучшен инструмент 'Объединение дублей'.
   Инструмент позволяет эффективно объединять дубликаты атрибутов. Имеет несколько режимов, включая искусственный интеллект.
   Полезен после импорта и парсинга.
2. Усовершенствован алгоритм импорта в формате CSV. Повышена производительность.
3. Добавлена возможность управления статусами атрибутов и их значений и их видимости в витрине.
4. Во всех формах редактирования метаданных Атрибутов, Дежурных шаблонов, Значений (в товаре) появилась кнопка автозаполнения с применением искусственного интелекта.
