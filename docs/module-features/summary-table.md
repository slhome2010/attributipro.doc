# Feature Reference Table

:::info Legend
  
- *Source*: Node(s) to be moved  
- *Target*: Destination node  
- *Level*: Node's hierarchy depth  
:::

| Operation | Mouse/Drag-and-Drop | Menu | Keyboard | Notes |  
|-----------|---------------------|------|----------|-------|  
| **Expand/Collapse Node** | Double-click |  |  |  |  
| **Select Node** | `Ctrl + Click` |  |  | Multi-select supported |  
| **Context Menu** | Right-click |  |  | Displays keyboard shortcuts |  
| **Add Group** |  | New Group | <kbd>Ctrl+M</kbd> |  |  
| **Add Attribute** |  | New Attribute | <kbd>Ctrl+Q</kbd> |  |  
| **Edit** | `Shift + Click` | Edit | <kbd>Shift+Enter</kbd> | Confirm: <kbd>Enter</kbd>, Cancel: <kbd>Esc</kbd> |  
| **Metadata Form** | `Shift + Click` in edit mode | Form | <kbd>F2</kbd> |  |  
| **Delete** |  | Delete | <kbd>Del</kbd> |  |  
| **Sort** | Drag-and-Drop | Cut > Paste | <kbd>Ctrl+X</kbd> > <kbd>Ctrl+V</kbd> | Source/target levels must match. Applies to groups/attributes within groups |  
| **Copy** |  | Copy > Paste | <kbd>Ctrl+C</kbd> > <kbd>Ctrl+V</kbd> | Attributes only. Paste target: group/category |  
| **Change Group** | Drag-and-Drop | Cut > Paste | <kbd>Ctrl+X</kbd> > <kbd>Ctrl+V</kbd> | Source: attribute. Target: group |  
| **Merge Attributes/Groups** | `Ctrl + Drag&Drop` | Cut > Merge | <kbd>Ctrl+X</kbd> > <kbd>Alt+V</kbd> | Same level required. Attribute-to-attribute only |  
| **Add Attribute to Category** | Drag-and-Drop | Copy > Paste | <kbd>Ctrl+C</kbd> > <kbd>Ctrl+V</kbd> | Source: attribute. Target: category |  
| **Change Category** | Drag-and-Drop | Cut > Paste | <kbd>Ctrl+X</kbd> > <kbd>Ctrl+V</kbd> | Source: attribute in "Category Attributes". Target: category in "Categories" tree |  
| **Remove from Category** |  | Delete | <kbd>Del</kbd> | From "Category Attributes" tree |  
| **Clone Duty Template to Other Languages** |  | Clone | <kbd>Alt+C</kbd> | Empty templates excluded |
