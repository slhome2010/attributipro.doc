# What's New in This Version

1. Improved the 'Merge Duplicates' tool.
   The tool allows you to efficiently merge duplicate attributes. It has several modes, including AI.
   Useful after importing and parsing.
2. Improved the import algorithm in the CSV format. Increased performance.
3. Added the ability to manage attribute and value statuses and their visibility in the storefront.
