# Attribute Value

Clicking on a table cell containing a **Value** will launch a modal window with a form for editing the **Value** itself and its [metadata](/general-info/metadata.md).

Editing **metadata** differs from editing the [**Duty Template**](/module-features/duty-features.md) only by the presence of the `SEO URL` field.

The `Attribute Value` field can be filled in manually or selected from ready-made **Values** in the dropdown list at the very top of the form. The list is formed according to [filter](/opencart-integration/value-filter.md) and [view](/opencart-integration/list-view.md) settings.

## Creating a Link (URL)

The purpose of this field was noted in the general description of [metadata](general-info/metadata.md).

The link can be entered manually or generated by clicking the 🔗 button to the right of the field. Generation will be based on the rules specified in the saved [profile](settings/interlink.md).

## Cloning

At the bottom of the form, next to the save and cancel buttons, there is a special checkbox `Apply to all languages`. If checked, when saving the form, [complete copying](/module-features/metadata-editing.md) of localizable data will occur for all languages.

## Setting as Duty Template

You can save all the data from this form as a **Duty Template** to reduce the time needed for creating it [in the module](/module-features/duty-features.md).

To do this, check the `Set as duty template` checkbox. The assignment happens when the form is saved.

:::warning
Control the state of this checkbox before saving. All settings are saved for the duration of the session, and the checkbox will remain in the same state when the next form is called, until you change it.
There is a possibility that you may overwrite existing **Duty Template** data.
:::

## Fill form from Duty Template

Click the 📄 button at the top of the header to auto‑fill all fields with **Duty Template** data.
