# Attribut&pro vs Attribut&co

Сравнительная таблица

| Фича | **Attribut&pro** | **Attribut&co** |
|:--|:--||:--|
| Создание новых групп и атрибутов в одном дереве | отображение всех **Значений** данного **Атрибута** для всех товаров, плюс **Дежурный шаблон** | отображение только **Значений** [Дежурного шаблона](general-info/duty.md) |
| `Категории` | отображение только **Значений** данного **Атрибута** для товаров из категорий отмеченных на вкладке **Связи** (не путать со **Значениями атрибутов категорий**) | отображение только **Значений** [Дежурного шаблона](general-info/duty.md) |
| `Дежурные` | отображение только **Значений** [Дежурного шаблона](general-info/duty.md) | отображение только **Значений** [Дежурного шаблона](general-info/duty.md) |
