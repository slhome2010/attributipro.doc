Профили URL

Управление профилями​

Вы можете добавлять, изменять, удалять профили. Выбор действия осуществляется кнопками справа от поля выбора.

Profile manage

Выбранный из списка профиль надо сохранить вместе с остальными настройкам. В дальнейшем он служит для автогенерации ссылок.

Редактирование профиля​

Форма редактирования позволяет настроить правила для формирования ссылок на посадочные страницы фильтра или перелинковки.

Profile form

Маршрут​

Страница сайта, на которой будут отображаться товары. Обычно product/category.

Полный маршрут выглядит так: index.php?route=product/category.

Алиас фильтра​

Краткое название фильтра, которое будет добавлено к маршруту. Например, mfp для Mega Filter Pro.

Аргументы​

Набор аргументов для формирования адресной строки. Доступны следующие переменные:

ПеременнаяОписание
{attribute_id}id атрибута
{name}название атрибута
{product_id}id товара
{main_category_id}id главной категории
{category_id}список категорий товара через разделитель
{path}путь категорий главная_категория_подкатегория...
{value}значение или список значений через разделитель
{alias}алиас фильтра (если он задан)

В процессе автогенерации вместо переменных будут подставлены их значения, взятые из БД.

Разделители​

Между блоками​

Разделитель между блоками параметров фильтра. Например: Атрибут1_Значение/Атрибут2_Значение.

Между атрибутом и значением​

Например: Атрибут_Значение.

Между значениями​

Например: Значение1,Значение2,Значение3.

Миграция SQL​

Вы можете воспользоваться готовыми таблицами, куда записаны примеры профилей. Таблицы входят в комплект поставки.

Импортируйте таблицу oc_attribute_interlink.sql в вашу БД.
