Группа кнопок

Button group

Назначение кнопок слева направо.

  • Обновить кэш модуля;
  • Проверить наличие обновлений;
  • Применить настройки без выхода из модуля;
  • Сохранить настройки и выйти;
  • Выйти без сохранения;

Кнопки теперь имеют индикатор загрузки.

Button with loading indicator
внимание

Кнопки Сохранить и Применить нужны только для сохранения настроек. Все изменения в узлах сразу синхронно записываются в Базу Данных.
