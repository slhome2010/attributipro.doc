Дежурный Шаблон

Создание дежурного шаблона​

Создание Дежурного шаблона производится на вкладке Атрибуты или на вкладке Атрибуты категорий, если в настройках дерева добавлен узел Дежурного шаблона.

На выбранном узле Дежурного шаблона нужно войти в режим редактирования, после чего ввести необходимые значения по умолчанию через разделитель если их несколько.

Если нужен доступ к Метаданным дежурного шаблона то при повторном нажатии Shift + Click в режиме редактирования или при нажатии F2 на выбранном узле, или через контекстное меню можно загрузить специальную форму.

Метаданные дежурного шаблона​

Каждый Дежурный шаблон может иметь дополнительные Метаданные, которые становятся в полном смысле Дежурными метаданными или метаданными по умолчанию, которые подставляются в метаданные Значения атрибута одновременно с Дежурным шаблоном.

Так выглядит форма Метаданных дежурного шаблона:

Duty metadata form

Назначение полей ввода и органов управления этой формы аналогичны описанным в этой статье.

Удаление дежурного шаблона​

Удаление (очистка) Дежурного шаблона производится через контекстное меню или клавишей Del.

Операцию можно производить только на вкладке Атрибуты. Данная операция не затрагивает товары. Удаляется только Дежурный шаблон со своими метаданными.

Клонирование дежурного шаблона​

Очень часто Дежурный шаблон представляет собой набор числовых значений, не нуждающихся в переводе на другие языки. Например, 20°C - 40°C, или 2G/3G (WCDMA/UMTS)/4G (LTE).

Заполнив Дежурный шаблон для одного языка, можно сразу клонировать его в другие языки.

Клонирование Дежурного шаблона производится через контекстное меню или по сочетанию клавиш Alt + C.

Метаданные клонируются вместе с Дежурным шаблоном.
