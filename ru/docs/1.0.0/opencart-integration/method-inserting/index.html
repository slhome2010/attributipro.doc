Cпособ вставки значений

При работе в рамках модуля Значения или Шаблоны в товар вставлялись в соответствии со Способом, который установлен в настройках Добавление значений атрибута в товар.

Чтобы каждый раз не менять базовые настройки, предусмотрена возможность оперативно переопределить Способ вставки значений. Эта настройка сохраняется на время сессии.

Values Insert Mode

Действие Способа распространяется на все операции с Дежурными шаблонами в форме товара.

Вставка Дежурного шаблона производится синхронно для всех языков. Физически это происходит в момент привязки к категории, а так же в момент выбора нового Атрибута.

подсказка

Если вы хотите добавить новые и защитить ранее введенные Значения, выбирайте способ вставки Только в пустые.
