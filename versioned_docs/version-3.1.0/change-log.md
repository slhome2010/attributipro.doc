# What's New in This Version

1. Added the 'Redistribute attributes' tool.
   This tool allows you to efficiently redistribute attributes among groups. It features several modes, including AI.
   It is highly useful after importing and parsing data.
2. Improved the 'Merge Duplicates' tool.
   The tool allows you to efficiently merge duplicate attributes. It has several modes, including AI.
   Useful after importing and parsing.
3. Improved the import algorithm in the CSV format. Increased performance.
4. Added the ability to manage attribute and value statuses and their visibility in the filter and product card.
5. In all forms of editing metadata of Attributes, Default templates, Values (in the product) there is an auto-fill button with the application of artificial intelligence.
