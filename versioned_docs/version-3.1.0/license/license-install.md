# License

## License Scope

The license is valid for one domain and one test domain. It must be evident that the test domain is genuinely used for testing purposes.

The license is not generated automatically. Therefore, after purchasing the module, you must send a request with the confirmed domain names to the personal mailbox on the website where the module was purchased.

:::warning
If you change the domain name, since the license is _"bound"_ to the domain and not to the purchaser, you will need to pay for a new license.🤷‍♂️
This is because I do not have a license server and cannot track which domain is active and which is not.
:::

## License Installation

Enter the received license key into the corresponding field under the _`Settings => General Settings`_ tab, then apply the settings by clicking the [_Apply_](settings/button-group.md) button.

:::info
The license key is stored in the following file:

```php
/system/license/attributipro.key
```

:::

If the key file is missing, the domain names do not match, or the key is corrupted, the module will operate in free mode. In this case, the label (free) will appear next to the module's name and version. For example:

**Attribut&pro v1.0.0 (free)**.
