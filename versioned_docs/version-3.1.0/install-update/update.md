# Update

## Step 1: Deactivating the Module

In the admin panel:

- Navigate to *Extensions ⇒ Modules*  
- Click "Deactivate" next to the **Attribut&pro** module

## Step 2: Copying New Files

Download the latest version and extract the archive. Open the folder corresponding to your [PHP version](/technical-specifications/compatibility.md).

In the admin panel:

- Go to *Extensions ⇒ Extension Installer*  
- Upload the `attributipro.3.x.ocmod.zip` file for OpenCart version 3.x from the appropriate folder

**For OCTEMPLATE users:** Follow the [installation instructions](/install-update/install.md).

## Step 3: Activating the Module

In the admin panel:

- Navigate to *Extensions ⇒ Modules*  
- Find the **Attribut&pro**; module  
- Activate the module

## Step 4: Refreshing Modifications

In the admin panel:

- Go to *Extensions ⇒ Modifications*  
- Click "Refresh"

## Step 5: Clearing Cache

**Be sure to clear your store and browser cache.**

## Step 6: Updating Settings

Open the module settings, make any necessary adjustments, and save them.
