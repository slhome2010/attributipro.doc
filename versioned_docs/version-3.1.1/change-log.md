# What's New in This Version

1. **Added the 'Redistribute attributes' tool**
   This tool allows you to efficiently redistribute attributes among groups. It features several modes, including AI-powered distribution. It is highly useful after importing and parsing data.

2. **Improved the 'Merge Duplicates' tool**
   The tool allows you to efficiently merge duplicate attributes. It now features several modes, including AI integration, which is particularly useful after data importing and parsing.

3. **Improved CSV Import Algorithm**
   The import algorithm for CSV format has been optimized, resulting in significantly increased performance and stability.

4. **Status Management**
   Added the ability to manage attribute and value statuses. You can now control their visibility in both the filter and the product card.

5. **AI Metadata Auto-fill**
   An AI-powered auto-fill button has been added to all metadata editing forms (Attributes, Default Templates, and Product Values).

6. **'Multiple Values (Templates)' Tab**
   Added a dedicated tab for managing multiple values. It includes splitter configuration and a robust exceptions mechanism (both manual and automatic) to prevent incorrect splitting of complex values and units containing slashes (e.g., `km/h`).

7. **'Sync Database' Tool**
   Added a database synchronization tool to restore data integrity. it recovers missing records in the `_pro` tables that may have been skipped by third-party tools or direct database modifications bypassing the OpenCart Event System.

8. **Prostore Theme Compatibility**
   Added compatibility with the Prostore theme. Module metadata (icons, tooltips, etc.) is now correctly displayed in the product characteristics section.
